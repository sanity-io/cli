`sanity deploy --external --url <origin>` now registers a federated studio that you host yourself, so the Dashboard loads it from your origin. Every federated deploy now sends its `mf-manifest.json` to the API alongside the build; once the API requires it, earlier CLI versions can no longer deploy federated apps or studios.
