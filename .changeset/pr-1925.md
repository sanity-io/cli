The generated studio entry now imports your `sanity.config` before `sanity`, and the app entry imports your app before `react-dom/client`. A side-effect import at the top of that file, such as `import 'react-devtools-cdt-mcp/register'` or any other tool that must install a global hook before React loads, runs before React initializes during `sanity dev`. A production `sanity build` can still evaluate shared dependency chunks before that code, so the same order is not guaranteed in the built bundle.
