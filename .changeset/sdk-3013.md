A host can pass `renderOptions.parentKey`, its own message bus connection key, when it renders a federated app or view. The SDK connects the rendered app with that parent, so the Dashboard hears it only while it hears the host.

The module id now reaches the SDK in the root context, alongside the parent key, and the separate module context is gone. Update the SDK together with the CLI: with only one of them updated, an app connects with its app id instead of its module id.
