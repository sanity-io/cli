`buildStudio` and `buildApp` from `@sanity/cli-build/_internal/build` now resolve to `{mfManifest}`: the parsed federation manifest for a federated build, `undefined` otherwise. A federated build that writes no federation manifest now fails, naming the missing file.

`checkBuiltOutput` is renamed to `readBuiltManifest`, moves from `@sanity/workbench-cli/deploy` to `@sanity/workbench-cli/build`, and resolves to the parsed federation manifest. `deployWorkbenchApp` takes the manifest as its `mfManifest` option instead of reading it from `sourceDir`.

`sanity deploy` sends the federation manifest from the build it has just run, and reads it from the output directory only when the build is skipped.
